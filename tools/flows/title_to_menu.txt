# MCLA scripted pad flow: FRESH profile, title -> save ALERT -> auto-save WARNING -> intro cinematic.
# Ported from the owner's iOS port (mac/flows/mcla_title_to_menu.txt), with the x86 changes listed below.
# Syntax: <second>:<button>[+<button>...][/<hold ms>], '#' comments; seconds count from process start.
# Read by tools/run_game.py (the three headers right here) and by the host's --input-file parser (comments are dropped).
#
# expect: menu
# seconds: 180
#
# 'expect' is the state run_game.py needs to see for exit 0: menu = the log shows `[mcla-heartbeat] first engine frame`
# and then `[mcla-state] Startup/Startup_Checks` (the title took Start and the save check began). 'seconds' is the
# default --seconds. Run with no fixture: a fresh user dir (empty profile) is what shows the ALERT.
#
# What the screens do (measured on the Mac port at 10 fps while loading; re-measure on x86 at M2 and fix this file):
#   legal text, Rockstar logo, MCLA logo + spinner, then the TITLE: live 3D city, 'PRESS (start)' bottom right
#   Start held 200-300 ms: camera fly-over, a map of Los Angeles with a spinner (LOADING)
#   ALERT 'A Midnight Club: Los Angeles save game could not be found ...':
#       CREATE A NEW SAVE GAME (default row) / RETRY / CONTINUE WITHOUT SAVING       A = CREATE A NEW SAVE GAME
#   WARNING 'This game uses an auto save feature ...'                                A = CONTINUE
#   'SAVING...' (mc4.sav is created), LOADING, black, then the intro movie (~40 s) ending on a still of the Carneys sign.
# The full chain on to free roam is new_profile_to_freeroam.txt; a saved profile is menu_to_freeroam.txt.
#
# Known trap: the title polls the pad every 2-4 updates, so Start is held 200-300 ms, and it is repeated because a press
# made before the title exists is lost. Extra Starts after the title are harmless. The dialogs are modal and wait for a
# button, so a late A costs only time, an early one (before the dialog exists) is ignored: A is repeated every 6 s.
# x86 change: the iOS file pressed Start once (44 s) and A twice (70, 80 s), timed for a 10 fps boot. This one repeats both.
# Extra A presses after the WARNING skip the intro movie and accept VEHICLE SELECT; that is harmless for this flow.
