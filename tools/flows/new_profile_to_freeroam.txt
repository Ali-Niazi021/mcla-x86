# MCLA scripted pad flow: FRESH profile all the way to driving in free roam, then PAUSE and drive.
# Ported from the owner's iOS port (mac/flows/mcla_new_profile_to_freeroam.txt), re-timed on x86 by the W2.1 bring-up
# (run w2.1-m3a: free roam at 136.9 s via `cutscene -> free-roam`, driving + the pause menu to 240 s).
# Syntax: <second>:<button>[+<button>...][/<hold ms>], '#' comments; seconds count from process start.
#
# expect: free-roam
# seconds: 240
#
# 'expect' is the state run_game.py needs to see for exit 0: free-roam = the log shows `[mcla-mode] <any state> -> free-roam`
# (a new profile logs `cutscene -> free-roam`, a saved one `loading -> free-roam`; `[mcla-state] Cruising/Cruising_Offline`).
# 'seconds' is the default --seconds. Run with no fixture (a fresh user dir). It also works on any fixture.
#
# Every dialog on the way is modal and waits for a button, so a press that comes late costs only time, and a press that
# comes early (before the screen exists) is ignored; that is why this file repeats presses instead of one per screen.
# Screens (t in s on x86, D3D12 720p, warm shader cache; t = process start):
#   ~4 first engine frame; legal, Rockstar logo, MCLA logo + spinner; the TITLE 'PRESS (start)' is up at ~27 s
#   ~28 the first Start that takes (held 300 ms; an earlier one is lost); Startup_Checks ~30.5, fly-over + map, then
#   <= 50 save ALERT                                 A = CREATE A NEW SAVE GAME (row 1 is the default; mc4.sav is created)
#   +3 s auto-save WARNING                           A = CONTINUE -> `front-end -> loading` -> 'SAVING...' -> 'LOADING'
#   +14-17 s after that A: the intro movie (`loading -> cutscene`), cut short by the next A
#   VEHICLE SELECT ('1998 SCIROCCO')                 A = accept (autosave) -> LOADING -> Carneys cutscene (~64 s, A skips lines)
#   ~137 'SAVING...' (autosave) + free roam + HUD    rt = throttle, ls_* = steer, Start = PAUSE menu (CONTINUE), B = close
# Without the A on the intro movie the movie plays (~40 s) and ends on a still of the Carneys sign: Start there -> VEHICLE SELECT.
# Known traps: the title polls the pad every 2-4 updates (Start is held 300 ms); the first save shows an ALERT
# (answer CREATE A NEW SAVE GAME, which is the default row, so A).
# The A chain runs to 155 s, past the arrival in free roam (~137 s): the iOS run had A presses there too and a cold shader cache
# can make the boot slower, so the margin stays. Do not add A presses after the throttle starts at 165 s.
