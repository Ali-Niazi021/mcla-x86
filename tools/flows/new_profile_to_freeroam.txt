# MCLA scripted pad flow: FRESH profile all the way to driving in free roam, then PAUSE and drive.
# Ported from the owner's iOS port (mac/flows/mcla_new_profile_to_freeroam.txt): verified there (Mac, Vulkan/MoltenVK,
# ~10 fps while loading): free roam with the car at t~150 s, driving + the pause menu to 240 s.
# Syntax: <second>:<button>[+<button>...][/<hold ms>], '#' comments; seconds count from process start.
#
# expect: free-roam
# seconds: 240
#
# 'expect' is the state run_game.py needs to see for exit 0: free-roam = the log shows `[mcla-mode] ... -> free-roam`
# (the game's own state machine, with `[mcla-state] Cruising/Cruising_Offline`). 'seconds' is the default --seconds.
# Run with no fixture (a fresh user dir). It also works on any fixture.
#
# Every dialog on the way is modal and waits for a button, so a press that comes late costs only time, and a press that
# comes early (before the screen exists) is ignored; that is why this file repeats presses instead of one per screen.
# Screens (t in s on the Mac; the early Starts also skip the legal / Rockstar-logo screens, so the title is up at ~24
# instead of ~40; re-measure on x86 at M3 and adjust this file):
#   legal 3-9, Rockstar logo 12-18, MCLA logo + spinner 21, title 'PRESS (start)' 24-27   Start held 300 ms (hold >= 200 ms)
#   fly-over + map ~30, save ALERT ~33              A = CREATE A NEW SAVE GAME (row 1 is the default; mc4.sav is created)
#   auto-save WARNING +3 s                          A = CONTINUE -> 'SAVING...' -> 'LOADING'; the intro movie is cut short by the next A
#   VEHICLE SELECT ('1998 SCIROCCO') ~65            A = accept (autosave) -> LOADING -> Carneys cutscene (~60 s, A skips lines)
#   'SAVING...' (autosave) + free roam + HUD ~148   rt = throttle, ls_* = steer, Start = PAUSE menu (CONTINUE), B = close
# Without the A on the intro movie the movie plays (~40 s) and ends on a still of the Carneys sign: Start there -> VEHICLE SELECT.
# Known traps: the title polls the pad every 2-4 updates (Start is held 200-300 ms); the first save shows an ALERT
# (answer CREATE A NEW SAVE GAME, which is the default row, so A).
# Caution: if free roam comes earlier than ~148 s on x86 the A presses that follow land on the street (the iOS run had
# none there); check the screenshots at M3 and end the A chain earlier if they do something.
