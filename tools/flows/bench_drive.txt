# MCLA bench flow, driving (tools/bench.py): free roam in a crowd, then a long drive.
# Ported from the owner's iOS port (tools/mcla/bench_flow.txt: dev008's flow_f60p extended). Run it with the after_intro
# fixture (run_game.py copies it into a fresh user dir).
# Format: <second>:<button>[+<button>...][/<hold ms>], '#' comments; seconds count from process start.
#
# expect: free-roam
# seconds: 360
# fixture: after_intro
#
# 'expect' is the state run_game.py needs to see for exit 0: free-roam = the log shows `[mcla-mode] ... -> free-roam`.
# 'seconds' is the default --seconds (the M4 bench runs 360); the pattern below continues to 450 s. bench.py measures from
# `-> free-roam` + 20 s to the end.
# T+8..24 Start presses reach free roam (parked in a crowd); T+30..42 B taps close a pause menu a late Start opened (E6: the
# robust sequence of E5; B is a harmless handbrake tap in free roam). T+50 the car drives: throttle held in 14 s slices, a
# gentle steer inside every slice (busiest street, then a quiet one); the pattern repeats to T+450 so a long bench keeps
# driving. No pause.
# Known trap: the title polls the pad every 2-4 updates, so Start is held 300 ms, and repeated because a press before the
# title exists is lost. An earlier Start at 12..36 toggled the pause menu inside the first segments on the Mac.
