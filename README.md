# Midnight Club: Los Angeles, recompiled for x86 (work in progress)

**Midnight Club: Los Angeles, statically recompiled for x86-64 (Windows first).**

Nothing is playable yet. The plan is in [docs/PLAN.md](docs/PLAN.md) once the planning pass lands.

> **You need your own copy of the game.** This repository contains no game
> files and no translated game code. Everything is read from your own dump
> of a disc you own. Do not ask for, or share, game files here.

This is a sister project of the iOS port (private, `mcla-ios`), which recompiles
the Xbox 360 build for Apple arm64 with the ReXGlue SDK. This one targets x86-64.
